Nasıl çalışır?

  • Delta sync saatte bir SGB API'sinin yalnız yeni kayıtlarını çeker (~1-3 dk). Sürekli çalışan tek mekanizma budur.
  • Full sync yalnızca ilk kurulumda bir kez elle çalıştırılır; zamanlı/otomatik çalışmaz. Geçmiş veri repo'da hazır gelir.
  • Domain listesi 100.000 satırlık parçalara bölünür; FortiGate her parçayı ayrı external resource olarak tüketir.
  • Tüm işlem GitHub Actions'ta çalışır, çıktılar GitHub Pages üzerinden Fastly CDN ile dağıtılır.
  • Veri kaynağı: SGB Open Threat Feed API
